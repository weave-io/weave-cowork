# Contributing

Contributions are welcome.

Before a pull request can be merged, its author must agree to a Contributor License Agreement (CLA). The CLA is being
set up. Until it is, please **open an issue first** to talk about what you'd like to change; don't send a pull request
yet.

The rules for building here are in [AGENTS.md](AGENTS.md); the design is in `mockups/cowork/`.

By contributing you agree that your contribution is licensed as described in [NOTICE](NOTICE): Apache-2.0 for
`src/CoWork.Runner` and `src/CoWork.Contracts`, AGPL-3.0-only for everything else.
